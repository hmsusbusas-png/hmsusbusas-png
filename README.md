# zaxdev

Захар, разработчик из Москвы. Делаю сайты на чистом HTML/CSS/JS без фреймворков и сборщиков, поэтому они быстрые и живут на GitHub Pages. На Python пишу Telegram-ботов на aiogram 3 и парсеры цен маркетплейсов.

Стек: Python, aiogram 3, JavaScript, HTML/CSS, Git.

## Что внутри

Сайты, все живые, на GitHub Pages:

- [zaxdev-portfolio](https://hmsusbusas-png.github.io/zaxdev-portfolio/): сайт-хаб всего портфолио, тёмная тема, glassmorphism

- [shum-agency](https://hmsusbusas-png.github.io/shum-agency/): сайт digital-агентства в нео-брутализме
- [utro-coffee](https://hmsusbusas-png.github.io/utro-coffee/): лендинг кофейни в тёплой редакционной вёрстке
- [forma-fitness](https://hmsusbusas-png.github.io/forma-fitness/): сеть фитнес-клубов, расписание и запись на пробную тренировку
- [marta-berg](https://hmsusbusas-png.github.io/marta-berg/): портфолио фотографа с masonry-галереей и лайтбоксом
- [metrics-dashboard](https://hmsusbusas-png.github.io/metrics-dashboard/): дашборд продаж на Chart.js с фильтрами и сменой темы

Боты и инструменты на Python:

- [wb-price-tracker](https://github.com/hmsusbusas-png/wb-price-tracker): следит за ценами на Wildberries, строит графики и выгружает в Excel

- [price-watch](https://github.com/hmsusbusas-png/price-watch): мониторинг цен с уведомлялками в Telegram, работает с Wildberries и любым сайтом по селектору
- [file-tidy](https://github.com/hmsusbusas-png/file-tidy): CLI-сортировщик файлов по типам и датам, dry-run по умолчанию, умеет откатывать изменения
